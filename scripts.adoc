== Scripts

The following scripts can be used with these test plans. 

[[volume-creation-and-deletion-scripts]]
* link:https://github.com/whyistheinternetbroken/Benchmarking/tree/main/ONTAP/volumes[Volume creation and deletion scripts] — create and delete data volumes.

[[lif-creation-and-cleanup-scripts]]
* link:https://github.com/whyistheinternetbroken/Benchmarking/tree/main/ONTAP/networking[LIF creation and cleanup scripts] — create and delete network interfaces.

[[netapp-afx-reinitialization-script]]
* link:https://github.com/whyistheinternetbroken/AFX[NetApp AFX reinitialization script] — re-initialize a cluster during this test plan. Review the README before use.

[[maximum-files-monitor]]
* link:https://github.com/whyistheinternetbroken/maxfile-increase[Maximum files monitor] — run as a scheduled job to monitor a volume for inode usage.

[[nas-performance-benchmark-scripts-benchmarkingontap-repo]]
* link:https://github.com/whyistheinternetbroken/Benchmarking/tree/main/ONTAP[NAS performance benchmark scripts (Benchmarking/ONTAP)] — NAS-specific benchmark and automation scripts referenced throughout this test plan, including the volume and LIF scripts above.
