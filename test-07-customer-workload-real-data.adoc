== Customer workload testing -- real data

The goal of these workload tests is to show that real data workloads can be ported over to NetApp AFX seamlessly and can potentially provide performance benefits over unified ONTAP -- particularly when growing the compute side of the cluster.

*Note:* For workload performance configuration (NFS, client/network, and ONTAP feature settings), see xref:test-07-08-performance-testing-configuration.adoc[Performance testing configuration (Tests 7 and 8)].

[cols="<1",width="100%"]
|===
<| *Test plan 7 - Customer workload testing -- real data*

a| *Test procedure:*

. Mount NetApp AFX volume using NAS protocol of your choice. Mount using NFS or SMB. For best results, use multiple simultaneous clients rather that testing a single client’s performance.

. Find the export path of your data volume in System Manager.
+
image::images/test-07-image-01.png[width=50%,link=images/test-07-image-01.png]

. Mount the volume using NFS. Optionally, include the mount path in /etc/fstab or automounter
+
*Note:* Recommended NFS versions and mount options are found in the xref:appendix-nfs-considerations.adoc#nfs-considerations[NFS considerations]. Run designated workloads against existing datasets that have been migrated over from unified ONTAP.

. While benchmarks are running, move on to xref:test-09-performance-monitoring.adoc[Performance Monitoring]. Test real-world data using everyday workloads. As workloads are running, test the limits of NetApp AFX by adding more clients or more jobs to the workload to push the limits of scale. See xref:test-11-compute-scaling.adoc[Compute scaling] for details.

a| *Expected outcome(s):*

* Workloads should not need additional configuration or changes to run properly using NetApp AFX.
* Performance should be as good or better than unified ONTAP.
|===
