== Providing feedback

We rely on our customers to provide detailed feedback throughout testing if at all possible. Product Management, Technical Marketing, and Engineering teams at NetApp will be actively involved in collecting and analyzing this feedback. [[overview]]
== Overview

NetApp AFX is a new NAS and object-only platform that takes standard ONTAP software and replaces the multi-aggregate architecture for a single shared capacity pool, where all nodes in a cluster can utilize the same shelves.
This disaggregated architecture offers a way to present an asymmetric number of compute nodes or storage shelves for cost-effective performance and capacity while offering the same ONTAP experience found with unified ONTAP.

Each ONTAP release delivers new features to improve overall performance, stability, usability, etc. This test plan is intended to be ever-evolving and include new features to test and try out. You can find version-specific feature tests in xref:TestPlan/test-plans.adoc#new-feature-tests-ontap-9191[Test Plans: New Feature Tests (ONTAP 9.19.1)].
